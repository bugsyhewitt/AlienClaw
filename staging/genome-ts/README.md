# @alienclaw/genome-codec (TypeScript)

Staged, standalone copy of AlienClaw's deterministic, checksummed genome codec.
It parses, validates, assembles, and mutates 256-character Base62 genomes. It
has no runtime dependencies (Node built-ins only in tests; none in `src/`).

Status: `0.0.0-dev`, `private`. This folder was copied out of the AlienClaw
tree while the rest of the agent product is retired; the in-tree sources it
came from (`src/alienclaw/registry/genome-codec.ts`, `genome-operators.ts`) are
unchanged. `PROVENANCE.json` records the source commit, blob hashes, and every
divergence.

## Genome format

| Section | Index | Chars    | Contents                                         |
|---------|-------|----------|--------------------------------------------------|
| IDENTITY  | 0   | 0–63     | ID tag (chars 0–7), generation, family           |
| EXECUTION | 1   | 64–127   | Xcode-encoded execution parameters               |
| BEHAVIOR  | 2   | 128–191  | Xcode-encoded behaviour parameters               |
| CHECKSUM  | 3   | 192–255  | 64-char checksum of chars 0–191                  |

The checksum is a dual 32-bit FNV-1a-style rolling hash over the 192 body
characters, expanded to 64 Base62 characters. An Xcode is a 2-char Base62 pair
holding an integer in `[0, 3843]`; each section holds 31 of them at bytes 1–62.

## API

```ts
import {
  // constants
  BASE62_ALPHABET, GENOME_LENGTH, SECTION_SIZE, SECTION_COUNT, SECTION, XCODE_MAX,
  PER_XCODE_MUTATION_RATE,
  // lifecycle
  computeChecksum, parseGenome, validateGenome, assembleGenome,
  // Xcode helpers
  encodeXcode, decodeXcode, xcodeToParamValue, paramValueToXcode,
  // operators
  mutateDirected,
} from '@alienclaw/genome-codec';
import type {
  SectionIndex, GenomeSections, GenomeValidationResult, ParameterField, SlotBrain,
} from '@alienclaw/genome-codec';
```

Subpath exports `@alienclaw/genome-codec/codec` and `@alienclaw/genome-codec/operators`
are also available. Exports point at the `.ts` sources (no build step); consumers
need a TypeScript-aware loader that maps `.js` specifiers to `.ts` files (tsx,
vitest). Node's built-in type stripping does not do that mapping.

| Function | Contract |
|---|---|
| `computeChecksum(body192)` | 64-char Base62 checksum; throws unless input is exactly 192 chars |
| `assembleGenome(i, e, b)` | body + checksum; throws unless each section is 64 Base62 chars |
| `parseGenome(g)` | splits into `{identity, execution, behavior, checksum}`; throws unless 256 chars (does not validate) |
| `validateGenome(g)` | `{valid, errors[]}`; never throws; checks type, length, alphabet, checksum |
| `encodeXcode(v)` / `decodeXcode(g, slot, xc)` | 2-char Base62 pair <-> int; range-checked |
| `xcodeToParamValue(x, min, max)` | `floor(x * span / 3844) + min` |
| `paramValueToXcode(p, min, max)` | smallest Xcode mapping to `p` (ceiling division) |
| `mutateDirected(g, slotBrains, rand, rate?)` | step-based directional mutation of slots 1–2 only; checksum recomputed; deterministic for a given `rand` stream |

## Relationship to GENOME_SPEC.md and the Python twin

- The normative description is `docs/specs/GENOME_SPEC.md` in the AlienClaw
  repo. It names this TypeScript codec as canonical; the Python implementation
  (`src/alienclaw/genome/`, staged separately) is its mirror.
- Both sides consume the same fixture, `test/fixtures/genome-spec-fixtures.json`
  (generated by `scripts/gen-testvectors.py`). A byte-identical copy lives in
  `test/fixtures/`; `test/fixture-sync.test.ts` fails if it drifts from the
  in-tree file, and skips when the package is used outside the repo.
- Operators are not cross-language reproducible: Python's `random.Random` and
  any JS PRNG differ, so the fixture's `mutate_invariant` / `crossover_invariant`
  cases only check that Python's outputs pass this validator. There is no TS
  crossover operator.

## Tests

```bash
vitest run staging/genome-ts                     # from the AlienClaw repo root
tsc -p staging/genome-ts/tsconfig.json           # strict typecheck, noEmit
```

- `codec.test.ts`, `xcode-helpers.test.ts`, `operators.test.ts`, `property.test.ts`:
  ported in-tree unit and property tests (imports rewritten).
- `fixture-runner.test.ts`: the shared cross-language fixture.
- `fixture-sync.test.ts`: byte-identity of the fixture copy.
- `parity-in-tree.test.ts`: staged vs in-tree outputs, errors, and PRNG
  consumption on fast-check inputs with a fixed seed; skipped outside the repo.
